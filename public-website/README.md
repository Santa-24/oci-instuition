# Odisha Competitive Institute (OCI) — Public Website

Official public web portal for **Odisha Competitive Institute (OCI)**, Bhadrak, Odisha (Established 17 January 2017).

Built with **Next.js 16.3 (Turbopack)**, **React 19**, **Tailwind CSS v4**, and **@base-ui/react**.

---

## 🏛️ Features & Architecture

- **The Academic Chronicle Design System**: Editorial typography, bespoke warm archival palette, dignified institutional layouts.
- **Pages**:
  - `/` — Institutional Hero, Trust Strip, Academy Overview, Exam Pathways, Mobile App spotlight.
  - `/about` — Academy heritage, founding story, methodology, leadership & physical infrastructure.
  - `/exams` — Comprehensive syllabi, eligibility criteria, and preparation roadmaps for SSC, Odisha State Govt, Railways, Banking, Defence, and Teaching exams.
  - `/why-oci` — The 8 Core Pillars of Academic Excellence and 4-phase pedagogical journey.
  - `/app` & `/download` — OCI mobile learning application preview, feature breakdown, and launch status.
  - `/success` — Student achievements, hall of fame, and merit testimonials.
  - `/contact` — Campus address (Nayabazar, Bhadrak), enquiry desk, helpline numbers, and direct admissions form.
  - `/privacy-policy` & `/terms` — Official institutional compliance documentation.
- **Database & Enquiries**: Integrated with Supabase REST backend for enquiry capture with offline CMS fallback resilience.

## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- npm or pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
